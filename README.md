# 🌆 Image Search App

A **React-based Image Search Application** that allows users to search for high-quality images using the **Unsplash API**.  
It features **infinite scrolling**, a **dark modern UI**, and the ability to **download selected images**.

---

## 🚀 Live Demo
👉 [Click here to view the live app](https://polagonimanasa.github.io/image-search-app/)

---

## 💡 Features

- 🔍 Search for images by keyword using Unsplash API  
- ♾️ Infinite scroll — loads more images as you scroll down  
- 💾 Download any image directly from the app  
- 🌙 Sleek dark theme for better viewing experience  
- ⌨️ Supports pressing **Enter** to search  
- 🔄 Resets search input automatically after search  

---

## 🧰 Tech Stack

- **React.js**  
- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  
- **Unsplash API**

### 🧑‍💻 Deployment

This project is deployed using GitHub Pages.

1. Install gh-pages if not installed:

   ```bash
   npm install --save gh-pages

2. Add homepage in package,json:

   ```bash
   "homepage": "https://polagonimanasa.github.io/image-search-app

3. Add deploy scripts in package.json:
   
   ```bash
   "scripts": {
    "predeploy": "npm run build",
    "deploy": "gh-pages -d build"
   }

4. Deploy to GitHub Pages:

   ```bash
   npm run deploy
